50K pedigree REML qualification against DMU

This benchmark compares gsuite 0.29.0 with DMU 5.6 on one frozen 50,000-animal pedigree using single-trait, multitrait, and rank-2 longitudinal animal models. It is a practical cross-software qualification, not a repeated performance benchmark or an exact simulation oracle.

The public gsim 0.2.0 generators are used unchanged. Their latent effects are not exact inbreeding-aware draws from the fitted relationship model, exact_relationship_draw is false, multitrait missingness follows gsim’s native observation patterns, and the realized phenotyped count is 42,497. Truth comparisons are therefore descriptive. The primary evidence is agreement between gsuite and DMU on the same frozen observations and pedigree.

Results

Back to all benchmarks · Public scope

The saved results below compare gsuite 0.29.0 and DMU 5.6. Both used direct pedigree REML on identical frozen data and starts. gsuite used CHOLMOD selected inversion; DMU used dmu1 followed by direct dmuai. Across the three models, the largest absolute covariance-estimate difference is below \(4.3\times10^{-8}\).

Prediction metrics use the predeclared first 1,000 pedigree-coded animals (856 phenotyped and 144 unphenotyped), not all 50,000 animals. The tables show Pearson correlation and normalized RMSE for each effect on that subset.

Timings are single executions on the same Intel Core i7-1365U Windows machine. gsuite times cover the fit; DMU times cover the dmu1 plus dmuai pipeline. They include different work boundaries and do not establish general speedups. See the selected hardware, software and thread settings and the convergence table below. The original development PDF is not part of this public snapshot.
