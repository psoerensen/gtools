Try the five-trait example

The large-single-step-5trait case simulates 10,000 individuals, including 2,500 genotyped at 4,000 markers. It estimates genetic and residual covariances, then predicts a breeding value for every individual on every trait.

Run the three stages with the v19 bundle

From the top of a fresh bundle with gsim and gsuite on your path, run:

mkdir -p data
gsim simulate cases/large-single-step-5trait/simulation.yml --output data/large-single-step-5trait
cd cases/large-single-step-5trait
gsuite run model-vc.yml --output results/vc
gsuite run model-blup.yml --output results/blup

Open results/blup/genetic_values.csv for the 50,000 labelled breeding values and results/vc/variance_components.csv for the 30 fitted covariance entries. The bundle includes Windows and GenomeDK commands in cases/SPLIT.md. Installation and access

Which cases passed?

Ordinary randomized Haseman–Elston estimation (RHE) followed by BLUP produced breeding values for 78 of 79 configurations, including all 17 frozen 10K cases. The checks used model-matched simulations for families originally represented by small examples.

Of the 78, 75 passed every requested output. Three more produced accepted breeding values, but only some individuals met the requested reliability precision across those runs. In the remaining four-founder dataset, genetic and permanent-environment effects had identical covariance patterns and their variances could not be estimated separately. The five-trait example ran end to end on Windows. GenomeDK execution of v19 is pending.

Find each example directory and its result in the 79-case index (CSV). For model settings, see the YAML guide.
