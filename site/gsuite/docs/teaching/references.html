Shared bibliography

Advanced notes: contents · Abbreviations

All chapters use the same author–year citation style and bibliography. Their reference sections list the works cited in each chapter; the complete list appears below. Further-reading suggestions explain the role of selected sources rather than implying that every source supports every model extension.
