gsuite

Modular computational libraries for statistical genetics

A unified interface to modular computational statistical-genetics libraries.

gsuite is an experimental R package for statistical genetics. Fit pedigree mixed models, prepare genotype data, and access selected methods from the suite’s native libraries. gsim is the companion R package for simulating genotypes, pedigrees and observations.

Start with a pedigree model

Supply two ordinary R data frames: observations in data and animal IDs and parents in pedigree. Describe the effects with a formula and fit the model:

library(gsuite)

fit <- gfit(
  formula = BW ~ sex + cohort + herd + (1 | id),
  data = data, pedigree = pedigree, task = "reml"
)
summary(fit)

This sketch assumes an installed gsuite and prepared data. The Tutorials provide the complete data preparation and explain single-trait, multitrait and longitudinal models. Starting variances are optional; explicit covariance components are available when needed.

The short interface currently supports one pedigree effect and one residual component. See the model catalogue for other interfaces and their supported models.

Installation status

gsuite has no public installation download yet. Its tutorial examples require a development installation of gsuite and an installed gsim. gsim and gact are already public. See Downloads for the separate package status.

Architecture overview

gsuite and gsim provide the analysis and simulation interfaces. gsuite provides analysis workflows, while gsim provides simulation workflows. Focused native libraries supply statistical methods, numerical solvers and genomic data operations. Each library has a defined responsibility and can evolve independently.

Role Components Responsibility
User-facing R interfaces gsuite, gsim Analysis and simulation workflows; gsuite remains in private development
Statistical libraries greml, gcorr, gscore Mixed models, genetic correlation and genomic scoring
Computational libraries gsolve, gmat, gbits Numerical solvers, genomic matrices and packed genotype operations

These groups describe responsibilities. The current gsuite R interface exposes selected native capabilities; integration coverage is documented in the method catalogue.

gtools also links to the public gact package for genomic association data and annotation workflows. This does not introduce a native build dependency between gact and the gsuite libraries.

See the complete responsibility and dependency model.

Libraries

The native gsuite development libraries remain private. gsim and gact have their own public repositories. The gsuite method catalogue is available here.

“Implemented” means that the capability is implemented in the development code and covered by relevant validation. It does not imply comprehensive benchmarking or Biobank-scale qualification.

Representative workflows

  • Matrices and correlation: genotype data → genomic matrices and LD → LD scores → correlation analyses
  • Scoring: genotype data + effects → genomic scores
  • Mixed models: observations + pedigree + formula → REML → estimates and predictions
  • Simulation: gsim → example data → gsuite analyses
